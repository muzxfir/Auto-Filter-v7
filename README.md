## ✨ Overview

**Auto-Filter-v7** is a powerful Telegram Auto-Filter Bot built using  
**Python, Pyrogram, MongoDB, and Docker**.

The bot helps Telegram groups search, filter, organize, and deliver files
automatically with interactive inline buttons.

- 🤖 Smart Auto Filter

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/muzxfir/Auto-Filter-v7.git
```

### 2. Open the project folder

```bash
cd Auto-Filter-v7
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file and add the required values.

```env
API_ID=
API_HASH=
BOT_TOKEN=
DATABASE_URI=
LOG_CHANNEL=
ADMINS=
```

### 5. Start the bot

```bash
python main.py
```

---

## ⚙️ Environment Variables

| Variable | Description |
|:---|:---|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Telegram bot token |
| `DATABASE_URI` | MongoDB connection URL |
| `LOG_CHANNEL` | Telegram log channel ID |
| `ADMINS` | Telegram user IDs of bot admins |

> Never share your bot token, API Hash, or database URL publicly.

## 🔐 Security

- Never commit your `.env` file.
- Never expose your `BOT_TOKEN`.
- Never publish your `API_HASH`.
- Never publicly share your MongoDB connection URL.
- Add secret files to `.gitignore`.

Example `.gitignore`:

```gitignore
.env
__pycache__/
*.pyc
venv/
.idea/
.vscode/
```
